# 📦 Капсула контекста: Проект Civis

## 🧠 Общая информация

**Проект:** Civis — Республика Профессионалов  
**Суть:** Платформа для создания доверительных сообществ через ИИ-матчинг на основе ценностей, поведения и целей.  
**Ключевая метафора:** Цифровая республика, где каждый пользователь — гражданин, а доступ к возможностям определяется рейтингом и активностью.

---

## 🎯 Основные цели

1. **Создать MVP Telegram-бота** для сбора профилей пользователей.
2. **Протестировать гипотезу спроса** на доверительный матчинг.
3. **Собрать базу первых пользователей** для дальнейшего развития.
4. **Подготовить логику для мобильного приложения** (Flutter).

---

## 🛠 Технический стек

| Компонент | Решение |
|-----------|---------|
| **Язык** | Python 3.12 |
| **Библиотека для бота** | `pyTelegramBotAPI` (синхронный) |
| **База данных** | SQLite (локальная) |
| **Прокси** | HTTP/SOCKS5 через Happ (порт 10809/10808) |
| **Хостинг** | VPS на cloud.reg.ru (временно) |
| **Репозиторий** | GitHub: `LeonidYasin/civis` |
| **Будущее** | Flutter-приложение + GitHub Actions для сборки |

## 🤖 Текущее состояние бота

### Функциональность
- ✅ Выбор языка (English / Русский)
- ✅ Анкета из 5 шагов:
  1. Имя
  2. О себе (минимум 20 символов)
  3. Выбор 3 ценностей (кнопки + накопление)
  4. Выбор роли (Исполнитель, Заказчик, Координатор, Инвестор)
  5. Выбор формата общения (Текст, Голос, Видео, Любой)
- ✅ Сохранение профиля в SQLite
- ✅ Команды: `/start`, `/profile`, `/survey`, `/offer`, `/request`, `/marketplace`, `/language`, `/status`, `/help`, `/cancel`, `/done`
- ✅ Смена языка в любой момент через `/language`

### Известные проблемы
- ❌ **Русский язык не работает** — в коде всё переведено, но кнопки и тексты остаются на английском. Причина — `TEXTS['ru']` заполнен английскими текстами. Нужно заменить на реальные русские переводы.
- ❌ **Маркетплейс** — пока заглушка (выводит "Marketplace is empty").
- ❌ **Прокси** — иногда не подхватывается системный прокси Windows, нужно явно указывать `PROXY_URL` в `.env`.

## 🔑 Ключевые файлы

### `bot_sync.py` — основной бот
- **Логика анкеты:** через состояния (`survey_name`, `survey_about`, `survey_values`, `survey_role`, `survey_format`).
- **База данных:** SQLite, таблица `users` (поля: `tg_id`, `username`, `name`, `about_text`, `user_values`, `role`, `format`, `language`, `status`, `created_at`, `updated_at`).
- **Команды:** реализованы через декораторы `@bot.message_handler(commands=['...'])`.
- **Прокси:** читается из `.env` через `PROXY_URL`.

### `.env` — переменные окружения
```env
BOT_TOKEN=ваш_токен
PROXY_URL=http://127.0.0.1:10809  # Или socks5://127.0.0.1:10808
```
