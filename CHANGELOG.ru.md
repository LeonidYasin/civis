# История изменений

Все значимые изменения в этом проекте будут документированы в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и этот проект следует [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Не выпущено]

### Добавлено
- Реальный ИИ-матчинг с OpenAI эмбеддингами (скоро)
- Интеграция платежей (Stripe/PayPal)

## [0.2.0] — 2026-09-06

### Добавлено
- **Модульные обработчики** — код разделён на `commands.py`, `survey.py`, `language.py`
- **Тарифы** — Бесплатный, Премиум ($9.99/мес), Навсегда ($99)
- **ИИ-матчинг** — команда `/match` с OpenAI эмбеддингами (заглушка)
- **Команда поддержки** — `/support` пересылает сообщения в группу админа
- **Уведомления администратора** — сообщения поддержки отправляются в `ADMIN_CHAT_ID`
- **Команды удаления** — `/delete_offer` и `/delete_request`
- **Команда поиска** — `/search <текст>` для поиска граждан
- **Кнопка "Назад"** — `/back` в процессе регистрации
- **Меню команд** — все команды видны в боковом меню Telegram
- **Поддержка русского языка** — полная локализация бота и документации
- **Многоколоночные клавиатуры** — оптимизированные раскладки (2-3 колонки)
- **Управление OpenAI ключом** — `/setkey` для сохранения API ключа

### Изменено
- **Схема базы данных** — добавлены таблицы `subscriptions` и колонка `openai_key`
- **Структура проекта** — реорганизован в пакет `handlers/`
- **Обновлён README** — отражены новые возможности

### Исправлено
- **Отображение клавиатуры** — исправлен `row_width` для ReplyKeyboardMarkup
- **Пересылка поддержки** — исправлен `ADMIN_CHAT_ID` с ID групп
- **Обработка команд** — добавлен недостающий импорт `ReplyKeyboardRemove`
- **Импорты локалей** — исправлена система переводов

## [0.1.0] — 2026-08-28

### Добавлено
- Первый релиз
- Регистрация пользователей (многошаговая: имя, о себе, ценности, роль, формат)
- Управление профилем (`/profile`, `/survey`)
- Список граждан (`/citizens`)
- Маркетплейс (`/offer`, `/request`, `/marketplace`)
- Мои предложения/запросы (`/my_offers`, `/my_requests`)
- Выбор языка (EN/RU)
- Эмбеддинг профиля (`/embedding`)
- Команды помощи и статуса
- База данных SQLite
- Поддержка прокси
