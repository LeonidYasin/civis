# Civis — Республика Профессионалов

Civis — это сообщество, где профессионалы соединяются на основе доверия, ценностей и общих целей. Проект состоит из двух основных частей:

1. **Telegram Бот** — MVP для регистрации граждан, маркетплейса и ИИ-матчинга.
2. **MCP Сервер** — сервер Model Context Protocol для интеграции с ИИ-агентами.

---

## 🚀 Возможности

### Telegram Бот (MVP)

- **Регистрация** — многошаговое создание профиля (имя, о себе, ценности, роль, формат)
- **Мультиязычность** — поддержка английского и русского языков
- **Управление профилем** — просмотр и обновление профиля
- **Список граждан** — просмотр всех зарегистрированных участников
- **Маркетплейс** — публикация и просмотр предложений и запросов
- **ИИ-матчинг** — семантический поиск и рекомендации через эмбеддинги
- **Тарифы** — Бесплатный, Премиум ($9.99/мес), Навсегда ($99)
- **Поддержка** — связь с разработчиком через `/support`
- **Уведомления администратора** — сообщения поддержки пересылаются в группу админа

### MCP Сервер

- **Инструменты GitHub Actions** — список запусков, получение ID последнего запуска, логи по шагам
- **Протокол Synapse** — публикация профилей, поиск людей, предложение контактов, индексация GitHub

---

## 🛠 Технологический стек

- **Бот** — Python 3.10+, pyTelegramBotAPI, SQLite
- **ИИ** — OpenAI API (эмбеддинги, матчинг)
- **MCP** — Flask-сервер с авто-обнаружением инструментов
- **Деплой** — GitHub Actions, Docker (опционально)

## 🚦 Быстрый старт

### Требования

- Python 3.10+
- Токен Telegram Бота (от @BotFather)
- API Ключ OpenAI (опционально, для ИИ-матчинга)

### Установка

```bash
# Клонирование репозитория
git clone https://github.com/LeonidYasin/civis.git
cd civis

# Установка зависимостей
pip install -r requirements.txt

# Копирование файла окружения
cp civis_bot/.env.example civis_bot/.env

# Редактирование .env
nano civis_bot/.env
```

### Запуск бота

```bash
cd civis_bot
python bot.py
```

### Запуск MCP сервера

```bash
cd mcp_server
python app.py
```

## 🧠 ИИ-матчинг

Civis использует эмбеддинги OpenAI для поиска совместимых пользователей:

1. Пользователь устанавливает OpenAI API ключ через `/setkey`
2. Профили конвертируются в эмбеддинги
3. `/match` находит семантически похожие профили
4. Результаты показывают процент совместимости и детали профиля
